# Carchi

اپ اندروید نگهداری خودرو: یادآوری تعویض روغن، شمع، تسمه، فیلتر و لنت بر اساس مدل خودرو و کیلومتر.

## ساختار

```
android/    اپلیکیشن اندروید (Kotlin + Jetpack Compose)
docs/       سند تصمیم، فلو، تحلیل رقبا و نسخه وب آزمایشی
```

## اجرا

```bash
cd android
./gradlew assembleDebug        # ساخت APK
./gradlew installDebug         # نصب روی گوشی/امولاتور وصل‌شده
```

خروجی: `android/app/build/outputs/apk/debug/app-debug.apk`

نیازمندی‌ها: JDK 17، Android SDK 36. مسیر SDK در `android/local.properties` است (این فایل در گیت نیست).

## وضعیت فعلی

نسخه ۰.۱ — آفلاین، بدون سرور، بدون ثبت‌نام.

- ثبت خودرو در سه فیلد
- لیست قطعات با وضعیت (سالم / نزدیک / سررسید)
- ثبت کیلومتر (دستی و +۱۰۰۰)
- «انجام شد» با کیلومتر، تاریخ و هزینه اختیاری
- تاریخچه سرویس
- ذخیره‌سازی محلی JSON

## قدم‌های بعدی

- اعلان محلی (WorkManager) با تبدیل کیلومتر به تاریخ
- کاتالوگ واقعی با منبع برای هر قاعده
- پشتیبانی از بیش از یک خودرو
- بک‌اند Go برای همگام‌سازی (بعد از اعتبارسنجی)
