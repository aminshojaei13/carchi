# Carchi (کارچی)

[![CI](https://github.com/aminshojaei13/carchi/actions/workflows/ci.yml/badge.svg)](https://github.com/aminshojaei13/carchi/actions/workflows/ci.yml)

اپ اندروید نگهداری خودرو: یادآوری تعویض روغن، شمع، تسمه، فیلتر و لنت بر اساس مدل خودرو، کیلومتر و زمان.

آفلاین، بدون ثبت‌نام، بدون سرور. داده‌ها روی خود گوشی می‌مانند.

## ساختار

```
android/    اپلیکیشن اندروید (Kotlin + Jetpack Compose)
tools/      اسکریپت‌های یک‌باره داده (استخراج کاتالوگ)
data/       خروجی داده‌ای تولیدشده
docs/       مشخصات، سناریوها، تصمیم‌های فنی و تحلیل‌ها
.github/    CI/CD (بیلد، لینت، تست، انتشار APK)
```

## اجرا

```bash
cd android
./gradlew assembleDebug        # ساخت APK
./gradlew installDebug         # نصب روی گوشی/امولاتور وصل‌شده
```

خروجی: `android/app/build/outputs/apk/debug/app-debug.apk`

نیازمندی‌ها: JDK 17، Android SDK 36. مسیر SDK در `android/local.properties` است (این فایل در گیت نیست).

## وضعیت فعلی — نسخه ۰.۳

- ثبت خودرو در سه فیلد (برند، مدل، سال، کیلومتر)
- لیست قطعات با سه وضعیت: سالم / نزدیک موعد / از موعد گذشته
- ثبت کیلومتر (دستی و +۱۰۰۰)
- «انجام شد» با کیلومتر، تاریخ و هزینه اختیاری
- تاریخچه سرویس + مجموع هزینه ثبت‌شده
- **ویرایش بازه تعویض** برای هر قطعه، مخصوص خودروی کاربر، با بازگشت یک‌ضربه‌ای به پیش‌فرض
- **تنظیمات کامل یادآوری در اختیار کاربر:**
  - روشن/خاموش کامل (هیچ اعلانی نمی‌آید)
  - انتخاب ساعت و دقیقه اعلان
  - «نزدیک موعد» یا «فقط گذشته از موعد»
  - انتخاب قطعه‌هایی که خبر بدهند
  - اعلان آزمایشی و میان‌بر تنظیمات اعلان سیستم
- **پشتیبان‌گیری و بازیابی** در یک فایل JSON
- ذخیره‌سازی امن: نوشتن اتمیک، بکاپ خودکار، عدم بازنویسی فایل خراب
- تاریخ شمسی و اعداد فارسی
- رابط کاربری کامپوننتی (تم، کارت، دکمه، فیلد، تب، شیت) با `@Preview` برای هر صفحه و کامپوننت

### محدودیت‌های صادقانه

- بازه‌های کاتالوگ **تخمینی** هستند، نه داده رسمی سازنده.
- اعلان در بعضی گوشی‌ها (سامسونگ/شیائومی) با بهینه‌سازی باتری محدود یا چند دقیقه delayed می‌شود.
- کاتالوگ فعلی ۲۳ مدل پرتکرار است؛ همه مدل‌ها نیست.
- چند خودرو در مدل داده آماده است ولی هنوز رابط کاربری ندارد.

## داده و کاتالوگ

- `android/app/src/main/assets/catalog.json` — کاتالوگ درون اپ (مدل‌ها + قطعات + بازه‌ها)
- `tools/import_khodrobank.py` — استخراج یک‌باره مشخصات فنی از khodrobank.com
- `docs/data-pipeline.md` — جزئیات، محدودیت‌ها و سیاست حقوقی

khodrobank بازه تعویض ساختاریافته ندارد؛ منبع آن فقط فهرست مدل‌ها و مشخصات فنی است. بازه‌ها از قواعد عمومی می‌آیند و با ویرایش کاربر اصلاح می‌شوند.

## CI/CD

- **CI** (`.github/workflows/ci.yml`): روی هر push/PR به `main` تست واحد، Android Lint، بیلد debug و release اجرا می‌شود و APKها و گزارش‌ها به‌عنوان artifact آپلود می‌شوند.
- **Release** (`.github/workflows/release.yml`): با push تگ `v*` (یا اجرای دستی) APK می‌سازد و به GitHub Release می‌چسباند.
- انتشار نسخه امضاشده اختیاری است. این secretها را در مخزن تنظیم کن:
  `CARCHI_KEYSTORE_BASE64`، `CARCHI_KEYSTORE_PASSWORD`، `CARCHI_KEY_ALIAS`، `CARCHI_KEY_PASSWORD`.
  بدون آن‌ها همان APK debug منتشر می‌شود.
- Dependabot ماهانه وابستگی‌های Gradle و Actions را به‌روز می‌کند.
